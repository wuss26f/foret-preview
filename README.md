# Forêt website preview

Static Forêt Flagstaff redesign with a white background, forest-green and gold accents, supplied logo and restaurant photos, a gallery, and the full-menu flipbook.

Run `python -m http.server 8000` from this directory and open http://localhost:8000 to preview. No installation or build is needed.

Edit `index.html` for layout and styles, `menu-inline.js` for the displayed menu content, `menu.js` for flipbook behavior, and `gallery.js` for the photo viewer. `menu-data.json` is a readable reference copy of the menu data; update it alongside `menu-inline.js` when menu content changes.

All required images, fonts, and the original menu PDF are included locally. Some gallery photos use AI-assisted clarity restoration. Confirm menu prices and opening hours with the restaurant before launch.
